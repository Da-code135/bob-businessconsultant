# Summary Format

Present immediately after Q8. Plain language only. No technical terms.
Gate: do not proceed to Phase 3 without explicit acceptance.

---

## OUTPUT

---
**PROJECT SUMMARY — For Your Review**
Bob-BusinessConsultant

---

### What This System Will Do
3–5 sentences. What it does, what problem it solves, what value it delivers.

### Who Will Use It and How
User types, how each interacts, which device.

### What This System Will NOT Do
3–5 explicit exclusions. Prevents scope creep.

### Rough Cost Expectation
Realistic range. Use local currency if known. Name cost drivers (development, hosting). No exact figures.

### Rough Timeline Estimate
Realistic range for 1–2 developers. Do not underestimate.
